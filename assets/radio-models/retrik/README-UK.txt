RETRIK — модель для RadioMaster TX16S / EdgeTX 2.11.3

Модель скопійована 25.10.2026 з активної RETRIK (model28.yml).
Мікси, трими, канали та USB MULTIAXIS збережено. Для передачі іншим
користувачам очищено лише modelRegistrationID власника.

ВСТАНОВЛЕННЯ НА ІНШИЙ TX16S
1. Збережіть резервну копію моделей свого пульта.
2. Підключіть пульт у режимі USB Storage (SD).
3. Скопіюйте TEMPLATES і IMAGES з цього архіву в корінь SD-картки.
   Якщо RETRIK.yml або racer4.jpg уже існують, спочатку збережіть їхню копію.
4. Безпечно від'єднайте накопичувач. На пульті: Manage Models → New Model
   → Personal → RETRIK. Так створюється нова модель, без заміни model28.yml
   чи списку ваших наявних моделей.
5. Для Pilot підключіть пульт як USB Joystick. У Pilot призначте джерела
   RC-каналів та перевірте їх за рухом стіків і тумблерів перед увімкненням.

КАНАЛИ З МОДЕЛІ
CH1 — Ail / крен; CH2 — Ele / тангаж; CH3 — Thr / газ; CH4 — Rud / рискання.
CH5 — SF (arm); CH6 — SA (switch, у файлі !SA та вага -100).
CH7 — P1 (cam); CH8 — P3 (cam); CH9 — SC (rejim); CH10 — SH (staCaM).
Фактичні функції AUX визначаються також налаштуваннями вашого контролера.

СУМІСНІСТЬ
Джерело — TX16S, модель у форматі EdgeTX 2.11.3. На іншій моделі пульта
потрібна адаптація органів керування через EdgeTX Companion; автоматична
сумісність із Boxer, Pocket, OpenTX та старішими EdgeTX не підтверджена.
Калібрування стіків, Stick Mode, USB-налаштування радіо, глобальні функції
та RF-прив'язка не переносяться цим пакетом. Модель зберігає зовнішній
модуль CRSF; для роботи лише через USB вимкніть непотрібний RF-модуль.
Перед польотом звірте напрямки, газ, ARM і всі AUX на землі без пропелерів.

Це модель EdgeTX для пульта. JSON-профіль осей у Pilot експортується
окремою кнопкою «Експорт профілю».
