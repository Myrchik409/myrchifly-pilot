# MyRcHiFlY Pilot

Окрема Windows-програма для REPIX: **RTSP-відео та USB-пульт**. Екран містить поле для посилання на відеопотік, кнопку запуску відео, призначення кнопок/осей пульта для RC1–RC16 і кнопку **«Увімкнути пульт»**. Програма не має вкладок налаштування польотного контролера й не записує його параметри.

## Користування

1. Підключіть REPIX через MAVLink UDP: введіть адресу `IP:порт` і натисніть **«Підключити»**. Остання адреса зберігається локально, але з’єднання після запуску програми саме не відкривається.
2. Вставте чинне посилання `rtsp://…` у поле **RTSP-адреса** та натисніть **«Показати відео»**. Останнє використане посилання, включно з токеном, зберігається локально на цьому комп’ютері. Відео після запуску програми саме не відкривається. Кнопка **«На весь екран»** відкриває повний екран.
3. Підключіть USB-пульт. У таблиці призначте осі й кнопки для потрібних RC-каналів або натисніть **«Визначити»** та рухніть відповідний орган керування. Перевірте значення на землі. Профіль зберігається на цьому комп’ютері; його також можна експортувати чи імпортувати.
   Новий профіль задає RC1–RC4 за схемою Mission Planner X/Y/Z/Rx. Якщо порядок USB-осей інший, натисніть **«Визначити»** у потрібному рядку, рухніть стіком і скоригуйте **«Реверс»** у тому ж рядку. На землі звірте «Пульт» і «Дрон»: крен вправо має підняти RC1, тангаж від себе — знизити RC2. Програма читає `RCMAP_*` та межі `RCx_MIN/MAX/TRIM` з підключеного ArduPilot, якщо контролер передає параметри. Експо та масштабування PWM відповідають логіці джойстика Mission Planner.
4. Натисніть **«Увімкнути пульт»**. Передача RC1–RC16 починається лише після цієї дії. При вимкненні пульта програма надсилає команду звільнення призначених каналів. При обриві зв’язку подальше звільнення залежить від таймауту RC override у контролері.
5. Кнопка **«Оновлення»** у верхній панелі перевіряє GitHub Releases. Нову версію можна завантажити й встановити після вимкнення пульта, відео та MAVLink. Інсталятор перевіряється за SHA-256, який публікує GitHub.

## Збірка

Потрібні Node.js і npm на Windows x64.

```powershell
npm ci
npm run typecheck
npm test
npm run dist:win
```

Інсталятор з’явиться в `release/`. Команда збірки завантажує бінарники Electron/FFmpeg та офіційний GStreamer runtime, якщо їх немає, і перевіряє SHA-256 GStreamer перед пакуванням. Вихідний код доступний за ліцензією GPL-3.0-only у [LICENSE](LICENSE).
